# Minecraft Foods 1.25.0

把 Minecraft 食物带进 PEAK：34 种食品、普通箱子掉落、烹饪变化、专属效果和 Minecraft 进食音效。

## 本次更新

### 食物全面加强

- 改用 PEAK 的饥饿回复与额外体力单位，取消 Minecraft 饥饿值、饱和度换算。
- 逐项对照同类原版食物的基础回复量，两个回复指标均不低于所选参考食品，多数基础档位提高约 10%–20%。
- 零食档为 12 点饥饿回复＋12 点额外体力，对照原版混合坚果的 10＋10。
- 面包为 18＋23，对照原版麦片棒的 15＋20；蘑菇煲为 45＋45，对照原版飞机餐的 40＋40。
- 所有食品首次加热都能提高回复；安全范围内重复加热不无限叠加。生肉和生鱼仍在原槽位变熟，同步更换名称、模型贴图和物品栏图标。
- 各食物保留独立烧焦、变毒、烧毁阈值。河豚、腐肉、蜘蛛眼等继续保留风险，强化的是正面回复，不取消其负面效果。

### 更清楚的物品说明

- 按 PEAK 习惯显示移除饥饿、获得额外体力、效果概率、持续时间、重量与下次烹饪结果。
- 兼容可选模组“物品信息显示增强版”1.1.3；未安装时也有内置效果说明。
- 烧焦食品显示当前实际回复与附加中毒，烧毁食品明确提示不能食用。

### Minecraft 进食音效

- 使用 SoundAPI 2.0.13 和随包 MCEat.mp3，在食用过程中播放。
- 松开、完成食用、切换或丢弃物品时停止，不再吃完后额外播放一次。
- 使用专用声音匹配规则，只影响本模组食品，并接入 PEAK 音效混音器。

### 特殊效果与代价

- 金苹果：5 秒无敌，5 秒内移除 20 点受伤，获得持续 60 秒的 20 点受伤吸收盾；无敌结束后倒地失控 3 秒。
- 附魔金苹果：12 秒无敌，20 秒内移除 80 点受伤，获得持续 60 秒的 80 点受伤吸收盾；60 秒内受伤减少 20%、免疫炎热增长；无敌结束后倒地失控 6 秒。
- 保留紫颂果安全落点随机传送、蜂蜜解毒、牛奶清除效果、迷之炖菜随机效果，以及有毒食物加热后毒性增加等功能。
- 普通箱子按稀有度分配食品，默认占每个掉落位置 25% 的总权重；不需要专属箱子。

## 安装依赖

- BepInExPack_PEAK 5.4.2403
- PEAKLib Core 1.7.2
- PEAKLib Items 1.6.2
- MonoDetour_BepInEx_5 0.6.7
- loaforcsSoundAPI 2.0.13

可选：cherrycove-ItemInfoDisplayForkedCNPlus 1.1.3（物品信息显示增强版）。

手动安装只需把包内 `plugins/MinecraftFoods` 文件夹放进 `BepInEx/plugins`，其中已包含进食音效。房主和加入者应安装相同版本。

## 验证与后续计划

本次完成编译、34 种食品回复对照和压缩包检查。1.25.0 的实际听感、UI 排版和多人游戏表现仍需游戏内测试。

药水系统尚未加入本版。僵尸化与体型变化仅完成代码调研，不属于已实现功能。
